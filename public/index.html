🎯 Why Linear SVM Outperformed All Other Models

TF-IDF text feature matrices contain thousands of dimensions. Support Vector Machines with a linear kernel excel in high-dimensional, linearly separable sparse text spaces by maximizing the classification margin, avoiding overfitting while requiring only 0.76s training time.

⚖️ Class Balance & Clean Dataset

The 9,865 deduplicated articles maintain near-perfect 50.68% Fake vs 49.32% Real balance. This eliminates class skew bias and allows F1, Precision, and Recall to evaluate authentic generalization.

Serverless Architecture on Vercel

This deployment replaces monolithic desktop Streamlit loops with a high-throughput, cloud-native Vercel Serverless Function architecture:

  • Frontend: Ultra-responsive, zero-bundle Tailwind UI served from edge CDN.
  • Backend: Stateless Python serverless function (api/index.py) running on Vercel Fluid Compute.
  • ML Inference Engine: Pre-warmed Linear SVM model (best_model.pkl) with TF-IDF Vectorizer (tfidf_vectorizer.pkl) sub-50ms inference.
  • Multi-Source Scraper: Auto-extracts transcripts from YouTube and articles from Wikipedia and news domains.
